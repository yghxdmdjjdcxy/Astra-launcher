Open Roles

核心

C# / WPF 启动器开发

负责启动器核心体验：实例、下载、Java、更新与稳定性。

  • C# / .NET、WPF 或 WinUI 基础
  • 理解异步、DI、MVVM 与文件系统边界
  • 愿意写测试，愿意处理真实用户环境的问题

扩展

Minecraft / Java 插件开发

围绕 Minecraft 生态做扩展：联机、服务端、MOD 与插件系统。

  • Java 或 C#，了解 Minecraft 启动/模组加载流程
  • 接触过 Fabric / Forge / NeoForge 更佳
  • 能排查日志、端口、网络与兼容性问题
✦
视觉

UI / UX 设计

让启动器更好看，也更好用：信息层级、交互反馈、动效与一致性。

  • 熟悉桌面端设计规范与基础可用性原则
  • 能交付可落地的设计稿 / 组件规范
  • 有条件参与 WPF XAML 还原者优先
✓
质量

测试 / QA

真实环境里把问题找出来：不同系统、不同 Java、不同网络与整合包。

  • 愿意按清单做回归测试并记录复现步骤
  • 能读懂日志、定位环境差异
  • 对边界条件有耐心，不放过“偶现”

社区

维护玩家社区，整理反馈，把复杂功能讲成普通玩家能懂的话。

  • 熟悉 Minecraft 玩家社区与常见问题
  • 能写清楚的公告、教程与版本说明

文档

文档 / 本地化

Why Astra

我们提供什么

这是一个认真对待工程质量的小团队。你做的改动会真实地到用户手里。

真实的产品场景不是练习题：下载、启动、联机、云盘，每一块都有真实用户。
可 review 的代码重视边界、测试和可维护性，欢迎把“能跑”升级成“可靠”。
远程协作以线上协作为主，按空闲时间参与，不强制坐班。
署名与成长贡献会记录在项目里；一起啃 .NET、WPF、Minecraft 与网络问题。
