常见问题

先看这里，能省一次提问。

这是官方启动器吗？需要正版账号吗？

不是 Mojang 官方产品。启动器支持 Microsoft 正版登录，也支持离线档案；使用正版账号才能进入正版服务器。

为什么第一次启动比较慢？

单文件版本首次运行会把 .NET 运行时解压到临时目录，之后启动会快很多。

支持 macOS / Linux 吗？

目前只提供 Windows x64 版本。项目是开源的，欢迎社区移植。

游戏崩溃了怎么办？

启动器会自动分析 latest.log 与 crash-reports，弹窗给出可逆修复建议；也可以点「补全游戏文件」重新校验客户端与依赖库。

会修改我已有的 .minecraft 吗？

导入实例只登记路径，删除实例不会删原目录；补全文件只会补齐缺失/损坏的本体文件，不动存档和模组配置。
